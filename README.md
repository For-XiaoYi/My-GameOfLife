# 生命游戏 · Conway's Game of Life

一个跑在浏览器里的康威生命游戏模拟器：1024×1024 的环形世界、可调迭代速度、预设图案库、
缩放平移、时间回溯、快照存档和演化片段回放。

**在线试玩：** https://for-xiaoyi.github.io/My-GameOfLife/

![生命游戏模拟器：1024×1024 环形世界，一片随机初始态演化 55 代后的样子](assets/screenshot.png)

*上面这张是在 1024×1024 的世界里撒一片随机初始态、跑 55 代之后截的：亮青色的格子是刚出生的，越暗说明这一格活得越久。*

## 开始玩

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **在线版** | 打开上面的链接 | 立刻玩，不用下载 |
| **单文件** | 双击根目录的 `生命游戏.html` | 离线玩、发给别人 |
| 自己构建 | `pnpm install` → `pnpm build` | 改代码 |

`生命游戏.html` 把 JS 和 CSS 全部内联进了一个文件，双击就能跑，断网也能玩。

## 玩法

- **画布**：打开就是平移工具，拖哪看哪；滚轮缩放（锚在光标处，0.03×–64×）、双指捏合、`0` 键看全图。
- **演化**：底栏 ▶ 播放/暂停（`Space` 也是）、单步 ⏭、速度滑杆 0.1–120 代/秒，右边 ∞ 是不限速（跑满一帧）。
- **世界是环形的**：上下、左右都相接，滑翔机从右边飞出去会从左边回来。
- **创造**：右侧图案库点一个图案 → 在画布上点一下就放下去；`R` 旋转、`M` 镜像，半透明幽灵
  预览会跟着鼠标走，越界会变红。没选图案时不会给你塞一个默认的，点图案库空白处也能取消选中。
  画笔/橡皮/直线/矩形在左侧工具栏，快捷键 `B E I U S`。画的过程中就改世界，松手才记为一步历史。
- **笔刷大小**：橡皮（和画笔）能调大小，最大 31×31。`Ctrl`+滚轮调大小，`[` `]` 也可以；
  滚轮本身始终是缩放。涂抹过程中光标会一直显示方框，看得出擦到哪了。
- **选择框存图案**：按 `K`（或点工具栏的虚线框）框住一块区域 → 底栏出现「删除 / 存为图案 / 取消」。
  起个名字、选个分类，它就进了右侧图案库，之后能像内置图案一样摆放、旋转、镜像。
  默认会存进「自定义」分组——还没有这个分组时会自动帮你建一个；分类下拉里也能改到别的组。
  - 拖框的**边或角**可以改大小（光标会变成 ↕ ↔ ⤡），拖框内的内容可以整块搬走；
  - `Alt`+拖框内只挪这个框、不动里面的细胞；`Shift` 拖动才是重新框选，`Esc` 放回原处；
  - 按住 `Ctrl` 再拖可以加第二块、第三块，几块会合成一张更复杂的图案；
  - `Del` 删掉框里的细胞，`Esc` 退出选择框；改大小、挪框、框选/取消框选都能 `Ctrl+Z` 撤销。
- **图案库可改**：点图案库右上角的 `⚙`，侧栏原地变成**编辑模式**（再点 `✓` 退出）——图案变成方块网格；
  拖分类标题排序，拖图案方块时会出现一个闪烁的虚线占位框，它插在哪里、松手后就落在哪里；
  顶部有「全部收起 / 全部展开」，`▼` 单独折叠某一组；`↓` 把图案收进下面的「仓库」，
  仓库里的点 `↑`（或双击）就放回图案库。分类名直接改，删分类会先问一句。
  这些改动和自定义图案都存在浏览器里，下次打开还在。
- **侧栏宽度**：拖侧栏左边缘可以调宽，浏览模式下默认 236px（3 列图案），拖宽后能铺开更多列；
  编辑模式默认 336px。两种模式的宽度各自记住。
- **侧栏收起**：点侧栏右上角的 `›`，图案库收成一个 `▦` 小图标，画布能多出两百多像素宽。
- **撤销**：`Ctrl+Z` 撤销上一步编辑，`Ctrl+Shift+Z` 重做（底栏的 ↶ ↷ 也行），框选/取消框选也能撤销。
- **时间回溯**：底栏时间轴可以拖回任意一代，`←/→` 单代微调。生命游戏本身不可逆，所以这里
  记录的是每一代**翻转了哪些格子**（增量编码），每 64 代存一个关键帧，拖动时从最近关键帧重放，
  所以拖到第 1 代和第 2999 代是一样快的。历史深度默认 3000 代。在历史中间按播放，就从那儿
  重新往下演化，原来的"未来"会被截断。
- **快照**：点「存档 → 保存当前」，连世界、代数、镜头一起记下来，点缩略图就跳回那一刻。
- **片段**：点「● 录制片段」开始录，演化一阵再点「■ 停止」，它就成了库里一段可以播放、
  拖动进度条的小电影。
- **自动存档**：存在浏览器本地，换浏览器或清缓存会丢；重要的东西用「存档 → 导出」存成
  `.life.json` 文件。
- **分享**：顶栏「分享」可以把当前画面存成 PNG、复制一条能还原这一刻的链接（世界内容压成
  RLE 塞在 `#` 后面，不经过服务器），或者全屏观看。
- **手机上也能玩**：单指绘制、双指捏合缩放、双指拖动平移；窄屏会自动收起图案库，顶栏的按钮
  可以左右滑动。

## 快捷键

| 键 | 作用 | 键 | 作用 |
| --- | --- | --- | --- |
| `Space` | 播放 / 暂停 | `B` `E` | 画笔 / 橡皮 |
| `←` `→` | 后退 / 前进一代 | `I` `U` | 直线 / 矩形 |
| `↑` `↓` | 放大 / 缩小 | `S` `K` | 摆放图案 / 选择框 |
| `0` | 适应全图 | `R` `M` | 旋转 / 镜像 |
| `G` | 网格 |
| `[` `]` | 笔刷变小 / 变大 | `Del` | 删选区内容 / 清空世界 |
| `Ctrl+Z` | 撤销（加 `Shift` 重做） | `Esc` | 退出选择框 |

## 一些实现上的取舍

- **时间回溯不做逆向计算**：规则本身不可逆，所以反过来「存每一代翻转了哪些格子」——每代只记
  变化的那几格，再每 64 代压一个关键帧兜住重放成本，于是拖到任意一代最多重放 64 步，
  历史也能存得很深。
- **渲染不靠逐个画格子**：每帧先把世界写进一块离屏像素缓冲（一格一个像素，查表取色），
  再一次性缩放贴到画布上；颜色按细胞存活时长取，新生的亮、活得久的暗，密度和年龄一眼可见。
- **一步演化是位并行的**：把一整行细胞压进 32 位整数，用「左右邻居 XOR、上下邻居 AND」这类
  位运算一次算 32 格，稠密图从 17 ms/代 降到 5 ms/代（浏览器里实测）。
- **世界是环形的**：坐标到边就绕回去，所以图案永远不会撞到墙。
