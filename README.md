# 生命游戏 · Conway's Game of Life

一个跑在浏览器里的康威生命游戏模拟器：1024×1024 的环形世界、可调迭代速度、预设图案库、
缩放平移、时间回溯、快照存档和演化片段回放。

**在线试玩：** https://for-xiaoyi.github.io/My-GameOfLife/

![生命游戏模拟器：1024×1024 环形世界，一片随机初始态演化 55 代后的样子](assets/screenshot.png)

*上面这张是在 1024×1024 的世界里撒一片随机初始态、跑 55 代之后截的：亮青色的格子是刚出生的，越暗说明这一格活得越久。*

## 开始玩

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **在线版** | 打开上面的链接 | 立刻玩，不用下载 |
| **单文件** | 双击根目录的 `生命游戏.html` | 离线玩、发给别人 |
| 自己构建 | `pnpm install` → `pnpm build` | 改代码 |

`生命游戏.html` 把 JS 和 CSS 全部内联进了一个文件，双击就能跑，断网也能玩。

## 玩法

- **画布**：滚轮缩放（锚在光标处，0.03×–64×）、拖拽平移、双指捏合、`0` 键看全图。
- **演化**：底栏 ▶ 播放/暂停、单步 ⏭、速度滑杆 0.1–120 代/秒，右边 ∞ 是不限速（跑满一帧）。
- **世界是环形的**：上下、左右都相接，滑翔机从右边飞出去会从左边回来。
- **创造**：右侧图案库点一个图案 → 在画布上点一下就放下去；`R` 旋转、`M` 镜像，半透明幽灵
  预览会跟着鼠标走，越界会变红。画笔/橡皮/直线/矩形在左侧工具栏，快捷键 `B E I U S`。
  画的过程中就改世界，松手才记为一步历史。
- **时间回溯**：底栏时间轴可以拖回任意一代，`←/→` 单代微调。生命游戏本身不可逆，所以这里
  记录的是每一代**翻转了哪些格子**（增量编码），每 64 代存一个关键帧，拖动时从最近关键帧重放，
  所以拖到第 1 代和第 2999 代是一样快的。历史深度默认 3000 代。在历史中间按播放，就从那儿
  重新往下演化，原来的"未来"会被截断。
- **快照**：点「存档 → 保存当前」，连世界、代数、镜头一起记下来，点缩略图就跳回那一刻。
- **片段**：点「● 录制片段」开始录，演化一阵再点「■ 停止」，它就成了库里一段可以播放、
  拖动进度条的小电影。
- **自动存档**：存在浏览器本地，换浏览器或清缓存会丢；重要的东西用「存档 → 导出」存成
  `.life.json` 文件。

## 一些实现上的取舍

- **时间回溯不做逆向计算**：规则本身不可逆，所以反过来「存每一代翻转了哪些格子」——每代只记
  变化的那几格，再每 64 代压一个关键帧兜住重放成本，于是拖到任意一代最多重放 64 步，
  历史也能存得很深。
- **渲染不靠逐个画格子**：每帧先把世界写进一块离屏像素缓冲（一格一个像素，查表取色），
  再一次性缩放贴到画布上；颜色按细胞存活时长取，新生的亮、活得久的暗，密度和年龄一眼可见。
- **世界是环形的**：坐标到边就绕回去，所以图案永远不会撞到墙。
